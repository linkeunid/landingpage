## Project Configuration

- **Language**: TypeScript
- **Package Manager**: pnpm
- **Add-ons**: prettier, eslint, vitest, tailwindcss, sveltekit-adapter

## Rules

- **Never edit `worker-configuration.d.ts`** — auto-generated by `pnpm wrangler types`. Add env vars to `.env` (dev) or `wrangler.jsonc` `vars`, then regenerate types.
- CSS only in `src/lib/styles/components/*.css` (Tailwind v4 `@utility` blocks, one file per page/component, BEM names: `home-page`, `home-page__title`, `shoji__lattice--end`), imported from `src/routes/layout.css` with relative paths (`$lib` doesn't resolve in CSS here) — never scoped `<style>` in `.svelte`, no long inline class strings or JS class consts, no inline `style`. `@import 'tailwindcss'` once in `layout.css`, `@theme{}` in `global/theme.css`, root rules in `global/base.css`, reusable pieces in `components/shared.css`. One spacing class beside a name is fine (`page__head mb-16`).
- New page/component: add `src/lib/styles/components/<name>.css`, import it in `layout.css` after `shared.css`, class names prefixed with the file name. `src/lib/components/ui/` wrappers stay unstyled.
- `pnpm gen` (`wrangler types`) after a `pnpm build` types `mainModule` from `.svelte-kit/cloudflare/_worker.js`, so `pnpm check` reports ~2k errors in `.svelte-kit/output`. Fix: `rm -rf .svelte-kit/{cloudflare,cloudflare-tmp,output}` then `pnpm gen`.
- Never add `eslint-disable svelte/no-navigation-without-resolve`: call `resolve()` inside the component (take a typed route like `to: '/'`), not a pre-resolved `href` prop.
- `src/lib` layout: `data/` (`site`), `utils/` (`cn`), `composables/` (`use-*.svelte.ts`, create when needed), `types/` (create when needed), `components/` (`layout/`, `ui/`). Helpers and components used by one route stay in that route folder; move to `lib/` once a second route needs them. Pure helpers live in `#lib` with unit tests beside them.
- Types/interfaces for helpers go in `src/lib/types/` or `routes/<page>/types.ts` for route-only ones; types derived from a constant use `import type { CONST }`. Component/page `Props` stay in the `.svelte` file.
- SEO: brand/description/keywords/publisher/JSON-LD in `src/lib/data/site.ts`; base meta in `routes/+layout.ts`, pages add `definePageMetaTags` (private pages `robots: 'noindex,nofollow'`). Only host `www.linkeun.com` is indexable (`isProd`); non-prod hosts get noindex meta + robots.txt `Disallow: /`. `site.indexed` lists public paths; `/sitemap.xml` emits each in every locale. EN at `/`, ID at `/id` (Paraglide `url` strategy + `urlPatterns` in `vite.config.ts`, hreflang in `+layout.ts`); internal links use `resolve(localizeHref(...))`. Share card: edit `scripts/og.html`, run `node scripts/og.mjs`.
- Deploy (mirrors s-app): push to `main` → `.github/workflows/deploy-beta.yml` → `beta.linkeun.com`; prod = run `deploy-production.yml` from a `v*` tag (actor in repo var `PROD_MANAGERS`) → `www.linkeun.com` + `linkeun.com` (apex 301s to www in `hooks.server.ts`), then GitHub release via `scripts/release-notes.sh`. Changing `wrangler.jsonc` needs `pnpm gen`.
- SvelteKit 3: `data-sveltekit-keepfocus`/`noscroll` are ignored (dev warning only); use `data-sveltekit-reset="false"` to keep focus + scroll on a GET form navigation.

Commit message format (every commit):

```
feat|fix|update|chore(scope): title

- item 1
- item 2
- item N
```

Type is one of `feat`, `fix`, `update`, `chore` (refactors go under `update`). Body is a bullet list of what changed, one item per line.

## Aesthetic

linkeun.com style: **joinery workshop**. Kumiko is joinery without nails, like the studio fitting apps together. Precise, measured, calm; not wabi-sabi (that is lkmn.link's).

House marks (identical in every Linkeun Mono app, never change per app): wordmark `Linkeun Mono` in `font-display` (Zen Old Mincho 900, wide tracking); footer hanko seal (`footer__seal`, `aka` vermilion, tilted, build SHA); `font-mono` (IBM Plex Mono) for small labels/links; grain overlay; footer note slot (`<Footer note>`, same placement/type in every app; the words are per app: lkmn.link "one encounter, one opportunity", linkeun.com "each piece cut to fit"); `aka` focus ring + selection.

This app (everything else is free per app; never copy another app's):

- Palette (`global/theme.css`): `washi` shoji-paper ground (#f3f3f0, neutral off-white like s-app; never cream/yellow), `ai` indigo ink (light), `kon` night indigo ground (dark), `shira` unbleached ink (dark), `nezumi` muted text, `aka` reserved for house marks + hover accents. No gradients or shadows.
- Type: `font-gothic` (Zen Kaku Gothic New) body, sentence case; `font-display` only for the wordmark.
- Layout: flush-left on a measured column (like a carpenter's drawing), planed rules (`home-page__rule`, hairline `border-t`) as joints; not centred. Home sections (Products, About, Contact) sit under a hairline with their name in a left margin column; EN + ID copy lives in `routes/home.ts` (`COPY[getLocale()]`), facts mirror each app's privacy page. Each product shows its one move drawn small (`home-page__slip`, `NewdaMap`) and one action (`home-page__act`, planed edge, no arrow).
- Motif: shoji (`Shoji.svelte`, kumiko lattice in two corners; cursor lights the paper from behind, revealing the grid). Navbar (absolute, scrolls away) and footer (in flow, page end) are open frames (no fill, one `--frame` border) so the fixed lattice and cursor light run through them; lattice + bars share `--bar`/`--frame`/`--pane-*` in `global/base.css`. lkmn.link = cursor glow + vertical deco lines.
- App switcher (`layout/AppSwitcher`, navbar end, alus `Popover` via `ui/Popover.ts`): every Linkeun Mono app as a pane in a 3-column kumiko grid (`gap-px` over `--bar`), short Latin monogram per app (`mark`, mono; no JP characters), current app stamped `aka`. App list in `#lib/data/apps.ts`; add new apps there. Opens focused on the first app; Escape, outside click or tabbing out closes.
- Motion: one load fade (`animate-fade-slide-down`), nothing bouncy.
- Dark (`kon`) is default; every colour utility needs a `dark:` pair.
